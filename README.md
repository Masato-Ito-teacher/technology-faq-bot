# 技術科AIアシスタント

中学校技術科の授業で実際に使える、わかりやすいFAQサイトです。  
生徒の質問に対して、キーワード検索とカテゴリ検索で簡単に答えを見つけることができます。

---

## 特長

- **31個のFAQ** - 6つのカテゴリで、よくある質問を網羅
- **キーワード検索** - 複数のキーワードに対応した精度の高い検索
- **カテゴリ別表示** - 「材料と加工」「情報」「エネルギー変換」「生物育成」「プログラミング」「安全」
- **カード形式** - カテゴリ別カラーで見やすいデザイン
- **スマホ対応** - タブレット・スマートフォンでも快適に利用
- **Googleサイト対応** - iframeに埋め込んでも余白が出にくい設計
- **先生向け** - `faqData.js` を編集するだけでFAQを追加できます

## 使い方

### キーワード検索

「木材を切る」「プログラミング」など、キーワードを入力して「検索」ボタンを押します。  
複数のキーワードをスペースで区切って入力すると、さらに精度が上がります。

### カテゴリから探す

カテゴリボタンを押すと、そのカテゴリのFAQがカード形式で表示されます。  
カードをクリックすると回答が拡大表示されます。

## FAQ の追加方法（先生向け）

`faqData.js` をテキストエディタで開き、追加したいカテゴリのセクションに以下のブロックを貼り付けてください。

### 追加テンプレート

```javascript
{
  category: "カテゴリ名",
  question: "質問文",
  answer: "回答文（1〜3文がわかりやすい）",
  keywords: ["キーワード1", "キーワード2", "キーワード3"]
},
```

### 使えるカテゴリ名（6種類）

| カテゴリ名 | バッジの色 |
|-----------|-----------|
| `"材料と加工"` | オレンジ |
| `"情報"` | 紫 |
| `"エネルギー変換"` | 水色 |
| `"生物育成"` | 緑 |
| `"プログラミング"` | ピンク |
| `"安全"` | 赤 |

### 追加例

```javascript
// === 材料と加工 セクションの末尾に追加する例 ===
{
  category: "材料と加工",
  question: "コンパスカッターの使い方は？",
  answer: "コンパスカッターは円形に穴を開ける工具です。中心を決めてからゆっくり回し、必ず保護メガネを着用してください。",
  keywords: ["コンパスカッター", "穴開け", "工具", "安全", "加工"]
},
```

### よくあるミス

| NG パターン | 正しい書き方 |
|-----------|------------|
| `category: 材料と加工` | `category: "材料と加工"` |
| 最後の `}` の後にカンマなし | `},` を付ける（最後の1件だけ不要）|
| `"answer": "..."` で改行をそのまま入力 | `\n` と書く |

### 保存後に画面が真っ白になった場合

`faqData.js` の文法エラーが原因です。  
VS Code（無料）で開くとエラー箇所が赤線で表示されるので確認してください。

## Googleサイトへの埋め込み方法

このFAQボットは **GitHub Pages** でホスティングして、**Googleサイト** に iframe で埋め込む形で使います。

### ステップ 1：GitHub Pages を有効にする

1. GitHubのリポジトリページを開く
2. 「Settings（設定）」→「Pages」へ進む
3. 「Branch」を `main` に設定して「Save」
4. しばらくすると `https://ユーザー名.github.io/リポジトリ名/` というURLが表示されます

### ステップ 2：Googleサイトに埋め込む

1. Googleサイトの編集画面を開く
2. ページ上の埋め込みたい場所をクリック
3. 右側パネルから「挿入」→「埋め込む」を選択
4. 「URLから」タブをクリックして、Step 1 で取得した GitHub Pages の URL を貼り付ける
5. 「挿入」をクリック

### ステップ 3：サイズを調整する

埋め込み後、フレームの端をドラッグしてサイズを調整します。

| 推奨サイズ | 値 |
|----------|---|
| 幅 | 100%（または最大幅に合わせる）|
| 高さ | 900〜1200px |

> **ヒント：** スマートフォンからアクセスする生徒が多い場合は、Googleサイトの「スマートフォンビュー」で見た目を確認してから公開してください。

### よくある質問（埋め込み時）

**Q：フレーム内でスクロールが2重になる**  
A：Googleサイト側のフレーム高さを増やすと解消されます。FAQ数に合わせて 1000〜1400px を目安にしてください。

**Q：フォントが崩れる**  
A：Googleサイト側のフォント設定には影響されません。`styles.css` の `body { font-family: ... }` で指定したフォントが優先されます。

**Q：更新しても古い内容が表示される**  
A：ブラウザのキャッシュをクリアしてください（`Ctrl + F5` または `Cmd + Shift + R`）。

## デザインのカスタマイズ

### 色を変えたい

`styles.css` の `:root` セクションを編集してください。

```css
:root {
  --primary: #2563eb;       /* メインカラー（青） */
  --primary-light: #3b82f6;
  --primary-dark: #1e40af;
}
```

### カテゴリバッジの色を変えたい

```css
:root {
  --cat-material:    #d97706;  /* 材料と加工 */
  --cat-info:        #7c3aed;  /* 情報 */
  --cat-energy:      #0891b2;  /* エネルギー変換 */
  --cat-biology:     #059669;  /* 生物育成 */
  --cat-programming: #db2777;  /* プログラミング */
  --cat-safety:      #dc2626;  /* 安全 */
}
```

[色選択ツール](https://www.w3schools.com/colors/colors_picker.asp) で好きな色を選んでください。
