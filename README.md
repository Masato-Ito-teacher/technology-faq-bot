# 技術科AIアシスタント 📚

中学校技術科の授業で実際に使える、わかりやすいFAQサイトです。  
生徒の質問に対して、キーワード検索とカテゴリ検索で簡単に答えを見つけることができます。

---

## 🎯 特長

✅ **31個のFAQ** - 6つのカテゴリで、よくある質問を網羅  
✅ **キーワード検索** - 複数のキーワードに対応した精度の高い検索  
✅ **カテゴリ別表示** - 「材料と加工」「情報」「エネルギー変換」「生物育成」「プログラミング」「安全」  
✅ **カード形式** - わかりやすく、見やすいカード式デザイン  
✅ **スマホ対応** - タブレット、スマートフォンでも快適に利用できます  
✅ **学校ホームページ風** - 中学校の雰囲気に合わせたデザイン  
✅ **先生向け** - FAQの追加が超かんたん

## 📁 ファイル構成

```
technology-faq-bot/
├── index.html       ← メインページ（ここをブラウザで開きます）
├── styles.css       ← デザイン用スタイルシート
├── script.js        ← 検索・表示・フィルター処理

```

### 各ファイルの説明

| ファイル | 説明 |
|---------|------|
| **index.html** | サイトのメインページ。HTML構造と見た目が書かれています。 |
| **styles.css** | サイトのデザイン（色、レイアウト、レスポンシブ対応）が書かれています。 |

| **faqData.js** | FAQ の内容が書かれています。ここに新しい質問を追加します。 |

## 🚀 使い方

### 1. ファイルを開く

`index.html` をWebブラウザで開いてください。  
（Google Chrome、Firefox、Safari、Microsoft Edge など、どのブラウザでもOKです）

```
ダブルクリック → index.html → ブラウザで開く
```

### 2. 質問を検索する

**方法①：キーワード検索**
- 「木材を切る」「プログラミング」など、キーワードを入力
- 「🔍 検索」ボタンを押す
- 関連する質問と答えが表示されます

**方法②：カテゴリから探す**
- 「材料と加工」「プログラミング」など、カテゴリボタンを押す
- そのカテゴリの全FAQがカード形式で表示されます
- 気になるカードをクリックすると詳細が表示されます

### 3. 検索精度について

このサイトは以下の順番で答えを探しています：

1. **完全一致** - キーワードと完全に同じ言葉（5点）
2. **部分一致** - キーワードが含まれている（2点）
3. **質問文マッチ** - 質問に含まれている（1点）

スコアが高い順に、最適な答えが表示されます。  
複数のキーワードで検索すると、さらに精度が上がります。

## 👨‍🏫 先生向け：FAQを追加・編集する方法

### FAQを追加したい場合

`faqData.js` をテキストエディタで開いて、以下の形式で追加してください：

```javascript
{
  category: "カテゴリ名",
  question: "質問文",
  answer: "回答文",
  keywords: ["キーワード1", "キーワード2", "キーワード3"]
}
```

#### 記入例：

```javascript
{
  category: "材料と加工",
  question: "コンパスカッターの使い方は？",
  answer: "コンパスカッターは円形に穴を開ける工具です。中心を決めてからゆっくり回し、必ず保護メガネを着用してください。",
  keywords: ["コンパスカッター", "穴開け", "工具", "安全", "加工"]
}
```

**コツ：**
- `category` は既存の6つのいずれかを選んでください
- `keywords` は5～8個、関連する単語を入れるとヒット率が上がります
- `answer` は1～3文で、わかりやすく書きましょう

### フォーマットに注意してください

- 最後の `}` の後には `,` を忘れずに（最後の項目は除く）
- 日本語は `"` でくくる
- 改行したいときは `\n` と書く

**NG 例：**
```javascript
{
  category: 材料と加工,  // ← ダメ：クォーテーションマークがない
  question: "質問",
  answer: "回答"  // ← ダメ：最後にカンマがない（リストの最後の場合は除く）
}
```

### 間違ったら

保存したときにサイトが真っ白になった場合は、`faqData.js` の文法にエラーがある可能性があります。

**チェック方法：**
1. Microsoft Visual Studio Code で `faqData.js` を開く
2. エラーが赤い波線で表示されます
3. 文法をチェックして直してください

テキストエディタは以下がおすすめです：
- Visual Studio Code（無料）
- Notepad++（無料）
- サクラエディタ（無料）

## 🎨 デザインのカスタマイズ

### 色を変えたい場合

`styles.css` の最初の部分を編集してください：

```css
:root {
  --primary: #2563eb;         /* 青色のメイン色 */
  --primary-light: #3b82f6;   /* 薄い青 */
  --primary-dark: #1e40af;    /* 濃い青 */
  /* ... 他の色 ... */
}
```

色は16進数カラーコードで指定します。  
[色選択ツール](https://www.w3schools.com/colors/colors_picker.asp) で好きな色を探してください。

### フォントを変えたい場合

`styles.css` の `body` セクションを編集してください：

```css
body {
  font-family: "Noto Sans JP", "Segoe UI", sans-serif;  /* ここを編集 */
}
```

### サイトのタイトルを変えたい場合

`index.html` の以下の部分を編集してください：

```html
<title>技術科AIアシスタント</title>  <!-- ここを編集 -->
<h1>技術科AIアシスタント</h1>        <!-- ここも編集 -->
```

## 🛠️ トラブルシューティング

### Q：サイトが真っ白で何も表示されない
**A：** `faqData.js` の文法エラーの可能性があります。以下をチェック：
- ダブルクォーテーション `"` が正しく閉じられているか
- 各項目の後に `,` があるか
- 最後の `}` の後に `,` がないか

### Q：検索してもスクリプトが見つからない
**A：** キーワードが登録されていない可能性があります。
- `faqData.js` で該当するFAQの `keywords` を確認
- キーワードを追加して保存してから、再度検索してください

### Q：ブラウザのキャッシュで古いデータが表示される
**A：** ブラウザのキャッシュをクリアしてください
- Windows: `Ctrl + Shift + Delete`
- Mac: `Command + Shift + Delete`
- または、`Ctrl + F5` で強制更新

### Q：ファイルが見つからないというエラーが出る
**A：** 以下をチェック：
- すべてのファイルが同じフォルダにあるか
- ファイル名に日本語が含まれていないか
- パスの区切り文字が正しいか（Windows は `\`、Mac・Linux は `/`）
